## Data Flow

1. User authenticates on React Native App using Firebase SDK.
2. Firebase returns a JWT UID.
3. React Native App calls AWS API Gateway with Firebase UID to access secured content.
4. AWS Lambda validates UID and queries PostgreSQL DB via Drizzle to fetch purchased courses.
5. Secure Vimeo links and PDF S3 URLs are returned to React Native for rendering in WebViews.
